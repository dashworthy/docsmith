# @docsmith/builder

A React + native-Tailwind document builder. You author a document as hand-written JSX using a
library of predesigned components, and the builder renders it to a **standalone HTML file** and to
**PDF** — the HTML is the single source of truth, and the PDF is a headless-Chrome print of it.
Light and dark themes are chosen at generation time. The output carries **no runtime JS**: code is
highlighted with Shiki and mermaid diagrams are pre-rendered to inline SVG, both at build time.

The design system mirrors the "Harvest × Bloom Parity" reference artifact — flat surfaces, IBM
Plex Sans/Mono + Familjen Grotesk, an accent plus role tints, comparison cards with neutral header
bands, phase cards, source cards, and a tint legend.

## Requirements

- **Node ≥ 18**, **npm**.
- **A Chromium-family browser** for PDF output. It is auto-detected (env `CHROME_PATH` /
  `PUPPETEER_EXECUTABLE_PATH`, then standard install paths, then the Chromium `puppeteer` installs
  for itself). HTML output needs no browser.
- Fonts load from Google Fonts via a `<link>`, so rendering fonts needs network. The HTML is
  otherwise fully self-contained (Tailwind CSS, diagrams, and code are inlined).

## Setup

```bash
cd builder
npm install
```

## Authoring a document

A document module default-exports the root element and may export a `title` (used as the HTML
`<title>`). Color, borders, and fonts come only through the typed token module — never raw hex —
so a single palette swap re-themes the whole document.

```tsx
// mydoc.tsx
import { Doc, Cover, Section, Callout, CodeBlock, Mermaid, Footer } from '../src/index.js';

export const title = 'My Document';

export default (
  <Doc>
    <Cover eyebrow="Spec · 2026-09-10" title="My Document" lede="One line under the title."
           chips={['v1', 'Approved']} />
    <Section eyebrow="Overview" title="What this is" deck="A short deck under the title.">
      <p>Body copy…</p>
      <Callout role="tip">A tip in the positive role.</Callout>
      <CodeBlock lang="ts" code={`const x = 1;`} />
      <Mermaid title="Flow" chart={`flowchart LR\n  A[Start] --> B[(Store)]`} />
    </Section>
    <Footer lines={['Generated by @docsmith/builder', 'reference · github.com/dashworthy/docsmith']} />
  </Doc>
);
```

## Generating output

```bash
# HTML (standalone file)
node --import tsx src/generate/cli.ts mydoc.tsx --theme light --format html --out mydoc.html

# PDF (printed from the HTML via headless Chrome)
node --import tsx src/generate/cli.ts mydoc.tsx --theme dark --format pdf --out mydoc.pdf
```

| Flag | Values | Default |
|---|---|---|
| `--theme` | `light` \| `dark` | `light` |
| `--format` | `html` \| `pdf` | `html` |
| `--out` | output file path | required |

A misspelled flag value is rejected rather than silently coerced.

## Component library

- **Chrome:** `Doc` (root), `Cover` (title band), `Section` (eyebrow + title + deck), `Footer`.
- **Inline & tables:** `Callout` (note/tip/important/warning/caution), `Badge`, `Table`, `Legend`.
- **Cards & panels:** `CompareCard` (neutral header band + two columns + target footer),
  `SourceCard`, `PanelGrid` / `Panel`, `KeyBox`.
- **Sequencing:** `Phases`, `Flow` (lanes + step chips).
- **Lists:** `QList` (numbered questions), `NonGoals` (struck items).
- **Code & diagrams:** `CodeBlock` (Shiki), `Mermaid` (pre-rendered SVG, recolored by shape).

## How it works

`generate()` renders the doc to static markup with `renderToStaticMarkup`, runs the pre-render
passes (Shiki code highlighting, then mermaid diagram rendering + per-shape recolor via the shared
Chrome), inlines the built Tailwind CSS through the HTML skeleton assembler, and writes the `.html`
— or, for `--format pdf`, prints that HTML with Puppeteer
(`page.pdf({ format:'A4', printBackground:true, displayHeaderFooter:false, preferCSSPageSize:true })`).

## Constraints (by design)

- **Native Tailwind only** — no `tailwind.config` `theme`/color/plugin customization. Exact colors
  are CSS variables read through native arbitrary utilities (`bg-[var(--surface)]`); the palette
  lives once in `src/theme/palette.ts`.
- **No runtime JS in the output.**
- Not `@react-pdf/renderer` — the PDF is a print of the HTML source of truth.
